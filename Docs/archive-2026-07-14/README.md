# Documentation Assets

This directory contains auto-generated assets for documentation.

## game-screenshot.png

Automatically captured screenshot of the game showing the latest development state.

- **Generated by**: `.github/workflows/screenshot.yml` GitHub Action
- **Script**: `scripts/capture-screenshot.ts`
- **Trigger**: Pushes to main branch affecting `src/` or `tests/` directories, manual workflow dispatch, or weekly on Sundays
- **Purpose**: Embedded in main README.md to show current game progress

### Manual Update

To manually update the screenshot locally:

```bash
npm run screenshot
```

This will:
1. Start the dev server
2. Open the game in headless Chrome
3. Skip the LLM splash screen if needed
4. Capture a screenshot of the game world
5. Save to `docs/game-screenshot.png`
